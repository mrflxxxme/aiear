## 2. Выбор стека (RF-only старт)

- **STT primary:** Yandex SpeechKit (лучшее ru + зрелый стриминг). **Fallback:** SaluteSpeech.
- **STT free-tier / офлайн:** Vosk или whisper.cpp on-device — нулевая маржинальная стоимость для бесплатных пользователей и офлайн-режима.
- **LLM-структурирование:** бенчмарк GigaChat ↔ YandexGPT (решение Q6). Старт на **GigaChat-2 Lite** (free 1M ток/мес) для дешёвого структурирования.
- **TTS (только с MVP-1+ при озвучке):** Yandex TTS или SaluteSpeech.

## 3. Unit-экономика — ВАЖНО (корректирует квоты Q7)

Стоимость транскрипции на Yandex SpeechKit ≈ **39 ₽/час** (0,65 ₽/мин), плюс LLM-структурирование ≈ **5–20 ₽/час** встречи → **all-in ≈ 45–60 ₽/час**.

Следствие для тарифов (net после комиссии RuStore 15%):
- **Standard 399 ₽ → ~339 ₽ net** → покрывает **~5–7 ч транскрипции/мес** до нулевой маржи по прямой AI-стоимости. Значит квота Standard должна быть **~5–8 ч/мес, а не 10–15.**
- **Pro 699 ₽ → ~594 ₽ net** → **~10–13 ч/мес** квоты.
- **Рычаги снижения себестоимости:** объёмные обязательства Yandex Cloud; on-device STT (Vosk/whisper.cpp) для бесплатного тира и части кейсов; кэп качества/частоты дискретизации; дешёвый LLM (GigaChat Lite) на структурировании.

> Вывод: квотная модель из Q7 верна, но **числа квот надо занизить** — на реальных ценах «10–15 ч за 399 ₽» уходит в минус. Рекомендую **Standard ~6 ч / Pro ~12 ч** + овередж-пакеты.
