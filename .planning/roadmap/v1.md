# V1 — Ассистент и расширение (vision реализуется) ⏸ СТАБ

> Здесь встаём против Дропс/Алисы. Спеки раскрывает `planner` JIT перед волной. Этот файл — якорь скоупа, не детальное ТЗ.

## Фазы (из PRD §V1)

| Фаза | Способность |
|---|---|
| **V1.1** | Hands-free ассистент (путь A): `ROLE_ASSISTANT` + `VoiceInteractionService` как опциональный «Power Mode»; детект сброса роли при обновлении |
| **V1.2** | Голосовой диалог + TTS (Yandex/SaluteSpeech) |
| **V1.3** | Выбор ИИ, включая intl (Claude/GPT) — через KZ-юрлицо + backend-прокси, с явным согласием на зарубежную обработку |
| **V1.4** | iOS-волна: капчер через «Привет, Siri → App Intent» + Control/Lock-widget + Action Button/Watch; биллинг по reader-app модели; on-device STT (iOS 26 SpeechAnalyzer) |
| **V1.5** | Гео-расширение: рус-Казахстан |

## Зависимости и предпосылки

- V1.1 требует роли default-ассистента (отложено из MVP по ADR-002/009).
- V1.3 требует KZ-юрлица (OPEN-QUESTION Q5) + ADR на intl-обработку ПД.
- V1.4 — отдельный нативный стек iOS; биллинг см. [ios-billing-options](../../docs/research/ios-billing-options.md).

## Примечание

Детализация V1 — преждевременна сейчас (поздние волны churn-ят). Раскрывается после гейта MVP-1.
