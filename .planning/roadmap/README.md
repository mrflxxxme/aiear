# Roadmap AIEAR (волнами, темп — агентный)

> Сроки не фиксируются по-недельно (соло+агенты): темп задаётся чёткостью спек, пропускной способностью ревью и исходом спайков. Детальные EARS — в [`specs/`](../../specs/). Метрики гейтов — [ADR-008](../decisions/ADR-008-metrics-north-star.md).

## Последовательность и зависимости

```
Wave 0 (спайки риска, БЛОКИРУЮЩАЯ)
   └─► MVP-0 «Поймай мысль» (free, до блеска) ──► MVP-0.x (доп. интеграции)
          └─► MVP-1 «Встречи/лекции» (биллинг ON)   ◄── монетизация стартует здесь
                 └─► V1 (ассистент/путь A, TTS, выбор ИИ/intl, iOS-волна, рус-KZ)
                        └─► V2+ (B2B/Enterprise, SDK, ООО)
```
