# MVP-1 — «Лекция / встреча» (включение биллинга) 🟢 ПРИОРИТЕТ ВЫРУЧКИ

> Денежный нарратив. Биллинг включается здесь. Детальные спеки раскрывает `planner` JIT перед стартом волны (стабы — [`specs/mvp-1/`](../../specs/mvp-1/)).

## Фазы

| Фаза | Способность | Pipeline |
|---|---|---|
| **M1** | Непрерывный захват 30–90 мин (на базе S1/S2), стриминг-транскрипт с тайм-кодами | android |
| **M2** | Структурированный протокол (тема/тезисы/задачи/вопросы/важное), экспорт PDF/MD/Obsidian/Notion | fullstack (+evaluator) |
| **M3** | Голосовая разметка по ходу («это важно» / «добавь к предыдущему») | android |
| **M4** | Экран явного согласия на запись («личный диктофон») | android (+reviewer-security) |
| **M5** | Биллинг (RuStore Pay SDK + свой эквайер): Free/Standard/Pro, квоты, рекуррент СБП, чеки 54-ФЗ | backend (+reviewer-security) |

## Зависимости

M1 опирается на Wave 0 S1/S2 (непрерывный фон). M5 опирается на Wave 0 S4 (RuStore Pay sandbox). M4 — обязателен до публичного запуска записи встреч (legal, Q4). M2 — `evaluator` мерит качество протокола.

## Гейт MVP-1 → V1

Free→Paid 3–6% · trial→paid · retention платящих · MRR · **gross margin >50%** после AI-стоимости (квоты держат маржу, ADR-005).
