# memory: billing-compliance

## [seed] 2026-06-23 — RuStore: дедлайны и рельсы
**Источник:** [tech-scenarios-findings](../../docs/research/tech-scenarios-findings.md).
RuStore — основной канal (~67 млн польз., комиссия 15%). Билить через **Pay SDK** (старый BillingClient выключен **01.08.2026**). С **01.02.2026** биллинг RuStore только для **ИП/ООО** (ИП есть). Методы: карты, **СБП (~53% платежей)**, SberPay, T-Pay. Подписки first-class (trial/grace/hold).
**Как применять:** M5 — сразу на Pay SDK, без BillingClient.

## [seed] 2026-06-23 — Внешний биллинг под 0% (рычаг)
RuStore разрешает внешний биллинг под **0%**. → дуальный рельс: RuStore Pay SDK в сторе + **свой эквайер** (CloudPayments/YooKassa) с рекуррентом по СБП и чеками 54-ФЗ для web/кросс-канала. ИП обязан выдавать чеки 54-ФЗ. НДС база 20%→22% с 01.01.2026.
**Как применять:** backend-engineer строит entitlement как единый источник для обоих рельсов.

## [seed] 2026-06-23 — Google Play = только бесплатный охват
РФ-разработчики не получают платежи (с 26.12.2024), РФ-пользователи не платят in-app. Play — только free-дистрибуция.

## [seed] 2026-06-23 — ФЗ-комплаенс
ФЗ-242: ПД россиян (вкл. аудио) — в RF-облаке (ADR-004). ФЗ-152: регистрация оператора ПД в РКН, политика, согласия. Запись встреч (MVP-1): экран явного согласия + фрейминг «личный диктофон» (M4, Q4 — legal).
**Как применять:** reviewer-security блокит любой ПД-поток за рубеж и любой billing без 54-ФЗ.
