## [seed] 2026-06-23 — Unit-экономика (драйвер квот)
STT ≈ **39 ₽/час** (0,65 ₽/мин) + LLM ≈ 5–20 ₽/час → **all-in 45–60 ₽/час**. Standard 399 ₽ (~339 net) покрывает ~5–8 ч/мес; Pro 699 ₽ (~594 net) ~10–13 ч/мес. → квоты занижать: Standard ~6 ч, Pro ~12 ч + овередж.
**Как применять:** backend-engineer/architect держат квоты в рамках ADR-005.
**Обновление 2026-07-07 (grill):** квоты ратифицированы ниже расчётных ради гейта маржи >50%: Free ~30 мин STT/мес (метрика — только минуты), Standard ~4 ч + on-device микс, Pro ~8–10 ч (по Q2). См. поправку в ADR-005.

## [seed] 2026-06-23 — WER мерить на своих данных
Заявленные вендором <8% оптимистичны. Цель — **<15% на ru-шуме** (метро, несколько спикеров). Мерить на собственном «грязном» аудио.
**Как применять:** evaluator гоняет adversarial-набор (шум/мат/2 спикера/смешанный язык), не доверяет вендор-цифрам.
