# memory/ — durable уроки (тегированные по домену)

> Общая тегированная память (решение грилла). Единственный писатель — `memory-curator`. Индексируется в AgentDB для семантического рекалла.

## Как устроено
- Один файл = один домен. Один durable-факт = одна секция с **датой** и **источником** (хендоф/аудит/ресёрч).
- Это **не** свалка заметок: попадает только то, что переиспользуемо между фазами (OEM-квирки, API-гочи, промпт-уроки, паттерны решённых багов).
- Спорное/одноразовое — не заносим (это решает curator при консолидации `learned`-полей хендофов).

## Домены
- [`android-oem.md`](android-oem.md) — поведение фона по OEM, киллеры, обходы.
- [`stt-llm.md`](stt-llm.md) — STT/LLM-уроки, WER, промпт-тюнинг, unit-экономика.
- [`cdm-bt.md`](cdm-bt.md) — CompanionDeviceManager, BT-активация, кнопки наушников.
- [`billing-compliance.md`](billing-compliance.md) — RuStore/эквайер, ФЗ-152/242, 54-ФЗ, дедлайны.

## Рекалл
Агент перед задачей: «был похожий баг/решение?» → семантический запрос AgentDB (или grep по `memory/`), **не** перечитывание всех прошлых фаз ([`01-CONTEXT-LOADING.md`](../agent-handbook/01-CONTEXT-LOADING.md)).

> Записи ниже с тегом `[seed]` — стартовые из ресёрча (до первого реального устройства). Проверяй на своём железе, апдейть после Wave 0.
