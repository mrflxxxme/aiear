## Раунд 1 — идентичность и платформа

| # | Вопрос | Решение фаундера |
|---|---|---|
| 1.1 | Имя продукта (PRD «EARAI» vs код «AIEAR») | **AIEAR** — рабочее название; бренд пока не описан. **Wake-word = «Buddy»**, произносится «Эй, бадди». PRD/глоссарий/S6 синхронизировать. |
| 1.2 | Продуктовый minSdk | **minSdk 31 + тиры возможностей**: полный screen-off mic-FGS-захват на Android 14+; деградация «капчер при активном приложении/экране» на 12–13. → ADR-014. |
| 1.3 | Модель аутентификации | **Аноним device-token в MVP-0 → опциональная привязка VK ID / Яндекс ID в MVP-1** (биллинг, мультидевайс-sync). → ADR-012. |
| 1.4 | Хостинг RF-облака | **Yandex Cloud** (ко-локация со SpeechKit → латентность S5, единый биллинг, managed Postgres+pgvector). → ADR-013. |

## Раунд 2 — монетизация и интеграции

| # | Вопрос | Решение фаундера |
|---|---|---|
| 2.1 | Метрика free-tier | **Минуты облачного STT: ~30 мин/мес.** После исчерпания — on-device черновой STT (F6) продолжает работать. Единое число в PRD/ADR-005/stack. |
| 2.2 | Конфликт «квота Standard ≈ break-even» vs «маржа >50%» | **Квота Standard ~4 ч/мес + on-device микс** (короткие/черновые капчеры — on-device). Цифры синхронизировать в PRD/ADR-005/stack. |
| 2.3 | Must-набор destination'ов F3 | **Must: Share/Markdown · Календарь · Telegram · Notes (встроенные заметки приложения). Obsidian → should** (едет в F3, но не держит гейт волны). Плюс: оценить встроенное хранилище заметок как «фазу 0» — принято, см. 3.1 / ADR-015. |
| 2.4 | Механизм записи в Obsidian | **SAF-запись .md-файла в папку vault (primary) + obsidian://new URI (fallback)**; точная схема YAML-frontmatter фиксируется в F3. |

## Раунд 3 — ИИ-контур

| # | Вопрос | Решение фаундера |
|---|---|---|
| 3.1 | Трактовка «Notes» | **Оба: встроенный inbox + Share в чужие заметки.** Каноническая модель — **inbox-first**: каждая мысль сначала персистится во внутреннее хранилище приложения; destination'ы — экспорты/пропагации из inbox. Локальное хранилище переезжает из F5 в фундамент F1. → ADR-015. |
| 3.2 | LLM по умолчанию (Q1) | **GigaChat-2 Lite дефолт**, провайдер — сменный адаптер за backend-прокси; бенчмарк GigaChat vs YandexGPT — evidence внутри F2 (не блокер). Q1 закрыт. |
| 3.3 | Числовые пороги качества ИИ | **Классификация типа мысли ≥85% на golden · WER STT <15% · F7: переспрос при confidence <0.7 для необратимых действий.** Пересмотр — только ADR'ом по данным, не молча. |
| 3.4 | Golden dataset F2/F7 | **Фаундер даёт 50–100 реальных реплик** (текстом достаточно); агент размечает и аугментирует до 300+ (перефразы, шум, adversarial); фаундер выборочно ратифицирует разметку. Задача — в founder-чеклист. |

## Раунд 4 — автономный контур и ops

| # | Вопрос | Решение фаундера |
|---|---|---|
| 4.1 | Native-фаза без device-evidence (ADR-010 ↔ ADR-011) | **Гибрид:** фаза закрывается `pass-with-followups`, runner продолжает; **merge в main блокирован** до device-evidence ИЛИ явного founder-ack на gap. Единая формулировка — в ADR-010 §5 и ADR-011 D3-native. |
| 4.2 | Device-петля и egress (Q9) | **FTL + egress-allowlist (maven.google.com/dl.google.com) + физ-Xiaomi батчем** + **эмулятор в Docker (уже установлен и работает у фаундера)** как промежуточный ярус device-петли. Q9 закрыт решением, исполнение — ops-чеклист. |
| 4.3 | Провижининг секретов (1–2 недели) | Фаундер заводит **все четыре**: Yandex SpeechKit ключ · GigaChat ключ · RuStore dev-аккаунт + Pay sandbox · GCP service-account (FTL). Свод — `ONBOARDING-SECRETS.md`. |
| 4.4 | Условия включения auto-merge | **Добавить 3-е условие:** Wave-0-green + CI-secrets + **«evidence-контур реально работает»** (единый путь evidence, машиночитаемый DoD, непустой manifest обязателен для нативных/AI-фаз). |

## Производные решения агента (impl/arch-форки, ADR-011 D4 — агент владеет, лог в DECISIONS-LOG)

| # | Форк | Решение | Обоснование |
|---|---|---|---|
| A1 | Протокол STT-стриминга (S5/F1) | **WebSocket** default; gRPC — только если S5 покажет, что WS не держит p95<2с | Проще прокси и клиент; S5 спроектирован это проверить |
| A2 | On-device STT движок (F6) | **Vosk** (ru, без внешнего ключа) | Нулевые внешние зависимости для free-тира; whisper.cpp — fallback при провале качества |
| A3 | Wake-word движок (S6) | **Vosk-keyword** сначала; Porcupine — только после добавления Picovoice-ключа в env | Не вводить новый секрет без нужды; wake-word теперь «Эй, бадди» |
| A4 | Единый API-контракт | `specs/_contracts/openapi.yaml` + `thought.schema.json` — канонические, спеки ссылаются, не дублируют | Иначе рассинхрон Android↔backend на fullstack-фазах |
| A5 | Единый путь evidence | Машинные `manifest.json` + `<gate>.json` живут **внутри** `specs/<wave>/evidence/<PHASE>/` | Свести две системы evidence в одну (аудит методологии, несостыковка №1) |
| A6 | Очередь фаз | `.planning/roadmap/phase-queue.yaml` (id/deps/status/spec_path) — машиночитаемый выбор «что дальше» | Убрать LLM-эвристику по прозе STATUS |
| A7 | Одобрение спеки под runner | Поле `status: approved` во фронтматтере спеки = машинный гейт (вместо неявного ручного шага) | Несостыковка №5 аудита методологии |
| A8 | Конвенция веток | `claude/<slug>` (фактическая harness-конвенция) канонизируется; `phase/*` — deprecated | 4 несовместимых конвенции → одна фактическая |
| A9 | Фискальный чек S4 | Документированное допущение: чек — на стороне эквайера (CloudPayments/YooKassa, 54-ФЗ), RuStore Pay — только подписка/рекуррент | На ратификацию в PR S4 (billing = tripwire) |
