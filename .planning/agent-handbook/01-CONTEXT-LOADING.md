# 01 — CONTEXT LOADING (дисциплина контекста = рычаг токенов №1)

> При Opus-дефолте (см. [`../../.claude/agents/_shared/model-routing.md`](../../.claude/agents/_shared/model-routing.md)) экономия токенов идёт **не от модели**, а отсюда. Это самое важное правило харнесса.

## Принцип

Каждый агент читает **минимальный достаточный срез**, не «весь репозиторий на всякий случай». Контекст — самый дорогой ресурс. Узкий контекст = дешевле, быстрее, меньше галлюцинаций.

## Бюджет чтения по ролям

| Роль | Грузит | НЕ грузит |
|---|---|---|
| `planner` | spec фазы + roadmap волны + релевантные ADR-заголовки + STATUS | чужой код, прошлые фазы целиком |
| `android-engineer` | spec фазы + свой task + `memory/android-oem.md` (если нативное) + затрагиваемые файлы `app/` | backend, чужие фичи |
| `backend-engineer` | spec фазы + свой task + затрагиваемые файлы `backend/` + контракт API | Android UI, чужие домены |
| `reviewer` | diff PR + spec-критерии + чеклист + ADR-refs из хендофа | весь репозиторий |
| `reviewer-security` | diff + security-чеклист + затронутые секрето/PII/billing-места | не-security код |
| `verifier` | EARS-критерии фазы + тест-репорты + device-матрица | исходники реализации (только если тест упал) |
| `evaluator` | промпт-кандидат + golden dataset + adversarial-набор | код приложения |
| `memory-curator` | хендофы фазы + текущие STATUS/JOURNAL/memory | исходники |
| `architect` | ADR-корпус + spec + аудит-входы | детали реализации, кроме инвариантов |

## Правила

1. **Читай по ссылке, не по поиску.** Хендоф/spec дают точные пути — открывай их, не сканируй дерево.
2. **Заголовки прежде тел.** Сначала фронтматтер/оглавление ADR, тело — только если релевантно.
3. **Рекалл вместо перечитывания.** «Был похожий баг?» → семантический запрос к AgentDB (или grep по `memory/`), а не чтение всех прошлых фаз.
4. **Не дублируй PRD в spec.** Spec ссылается на PRD-секции, не копирует их.
5. **Сжатый хендоф.** Передавай выводы и пути к артефактам, не пересказывай их содержимое.
6. **Эфемерность.** Закончил task → отдал хендоф → освободи контекст. Не держи состояние «про запас».

## Анти-паттерны (block на ревью)

- ❌ `Read` всего `app/` чтобы «понять контекст».
- ❌ Чтение всех ADR, когда нужен один.
- ❌ Пересказ PRD внутри хендофа.
- ❌ Грузить backend-код в Android-задаче.
