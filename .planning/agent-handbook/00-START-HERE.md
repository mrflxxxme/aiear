# 00 — START HERE (точка входа агента)

> Ты — ИИ-субагент в харнессе AIEAR. Этот файл даёт mental model за 2 минуты. Не читай весь репозиторий — читай **свой срез** (см. [`01-CONTEXT-LOADING.md`](01-CONTEXT-LOADING.md)).

## Что строим

Android-капчер «второй мозг» (см. [`../PROJECT.md`](../PROJECT.md)). Продуктовая истина — [`../../docs/EARAI-PRD.md`](../../docs/EARAI-PRD.md). Этот харнесс — обвязка, которой ты исполняешь PRD силами профильных агентов.

## Маршрут чтения при спавне (строго в этом порядке, минимально)

1. **`../../CLAUDE.md`** — канон + жёсткие правила (уже в контексте проекта).
2. **`.claude/agents/<твоя-роль>.md`** — твоя миссия, tools, чеклист, шаблон хендофа.
3. **`specs/<активная-фаза>/<PHASE>.md`** — spec фазы с EARS (если ты в фазовой работе).
4. **Входящий хендоф** в `.planning/_handoffs/<phase>/` — что передал предыдущий агент.
5. **Только при необходимости:** релевантный `.planning/memory/<domain>.md` или AgentDB-рекалл.

Всё. Не грузи остальное.

## Ментальная модель пайплайна

```
Wave (роадмап + go/no-go-гейт)
  └─ Phase (1 spec + 1 plan + 1 PR + 1 phase-аудит)
       └─ Task (ты исполняешь одну, отдаёшь хендоф, умираешь)
```

Поток фазы: `planner` → impl (`android-engineer` ∥ `backend-engineer`) → ревью (`reviewer` ∥ `reviewer-security`) → `verifier` → **phase-аудит** (`architect`) → `memory-curator` → **фаундер-гейт** → merge. Подробно — [`02-PIPELINE.md`](02-PIPELINE.md).

**Автономный runner (ADR-011):** фазы сцепляются через `/autonomy:run`; ты владеешь impl+arch-форками (решаешь+логируешь), эскалируешь только продукт/рынок + трипвайр. Режим сейчас — rails-first (auto-merge off, пауза на ack на каждом PR). Гайд — [`08-AUTONOMOUS-RUNNER.md`](08-AUTONOMOUS-RUNNER.md).

## 6 правил, которые нарушать нельзя

1. **Делай ровно spec.** Неясность → `task.unclear` к `planner`. Не додумывай.
2. **Грузи только свой срез** (токены — рычаг №1).
3. **Никаких секретов в коде/коммитах.** ПД россиян — только RF-облако.
4. **Отдавай лёгкий хендоф** ([`03-HANDOFF.md`](03-HANDOFF.md)) — это и есть твой выход.
5. **Память пишет только `memory-curator`.** Ты предлагаешь уроки полем `learned` в хендофе.
6. **Застрял >30 мин или 3 цикла** → эскалация ([`05-ESCALATION.md`](05-ESCALATION.md)), не крути впустую.

## Куда писать

- Артефакты работы (код, тесты) — по [`_meta/conventions.md`](../_meta/conventions.md) §2.
- Хендоф — `.planning/_handoffs/<phase>/<from>-to-<to>.md`.
- Никогда не пиши в STATUS/JOURNAL/memory напрямую — это зона `memory-curator`.
