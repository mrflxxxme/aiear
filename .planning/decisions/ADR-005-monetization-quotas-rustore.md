# ADR-005 — Монетизация

## Контекст
Себестоимость STT ≈ 45–60 ₽/час all-in делает «безлимит» убыточным. RuStore Pay SDK — обязательный канал (старый BillingClient выключен 01.08.2026); монетизация только для ИП/ООО (ИП есть). RuStore разрешает внешний биллинг под 0%.

## Решение
**Квотная модель:** Free (0 ₽, без карты, ~30–60 заметок/мес или ~30 мин STT) / **Standard ~399 ₽** (~6 ч/мес) / **Pro ~699 ₽** (~12 ч/мес) + годовой (−20–30%). Биллинг включается с **MVP-1**. Дуальный рельс: **RuStore Pay SDK** (15%) в сторе + **свой эквайер** (CloudPayments/YooKassa, СБП-рекуррент, 0%, чеки 54-ФЗ) для web/кросс-канала. Юрлицо — **ИП**.

## Поправка 2026-07-07 (grill, ратифицировано фаундером)
Исходные квоты (Standard ~6 ч при break-even ~5–8 ч) противоречили гейту MVP-1→V1
«маржа >50%» (ADR-008). Ратифицированные квоты: **Free = ~30 мин облачного STT/мес**
(единственная метрика лимита — минуты, не заметки; после исчерпания on-device STT
работает бесплатно), **Standard ~399 ₽ = ~4 ч/мес + on-device микс**, **Pro ~699 ₽ =
~8–10 ч/мес (уточняется по Q2)**. Канон: `GRILL-2026-07-07-project-docs.md` §2.1–2.2.

## Последствия
- Квоты занижены под реальную unit-экономику ([android-ru-tech](../../docs/research/android-ru-tech.md)) с запасом на маржу >50%: Standard ~4 ч, Pro ~8–10 ч + овередж-пакеты.
- on-device STT удешевляет free-тир и разгружает облачную квоту платных тиров (короткие/черновые капчеры).
- `reviewer-security` проверяет идемпотентность, отсутствие списаний сверх квоты, чеки 54-ФЗ.

## Альтернативы (отклонены)
- **«Безлимит» 299/599** — уходит в минус на STT.
- **Только Google Play** — РФ-разработчики не получают платежи.
- **Только RuStore-биллинг (15%)** — упускает 0%-внешний рельс.
