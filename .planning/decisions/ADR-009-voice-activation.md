# ADR-009 — Голосовая активация

## Контекст
Полноценный always-on hotword (приложение убито / без наушников) ОС резервирует за default-ассистентом. Но внутри уже работающего сервиса программный hotword и голосовые команды возможны.

## Решение
- **Голосовые команды в сессии (F7)** — полностью в MVP-0: разметка, выбор destination/CTA, подтверждение/отмена без касания экрана. При низкой уверенности — переспрос перед необратимым действием.
- **wake-word «Эй, бадди»** (Buddy; поправка 2026-07-07 — имя AIEAR рабочее, фраза активации отвязана от бренда, grill §1.1) — только на **взведённом сервисе пока наушники подключены** (CDM → mic-FGS → on-device hotword: Picovoice Porcupine / Vosk). Валидируется спайком **S6** (бюджет батареи ≤3%/ч, VAD-гейт; стоп слушания при отключении наушников). Исход S6 решает скоуп MVP-0.x.
- **Anytime-hotword** (убитое приложение / без наушников) — **вне скоупа MVP**, только V1 (путь A, default-ассистент).

## Последствия
- S6 — оценочный спайк (не блокирует MVP-0, но определяет MVP-0.x).
- F7 требует распознавания команд внутри STT-сессии — `evaluator` мерит точность.

## Альтернативы (отклонены)
- **Always-on hotword в MVP** — невозможно без роли ассистента; отложено в V1.
