# ADR-008 — Метрики и гейты

## Контекст
PRD v1.0 ставил vanity-цифры (150k MAU, MRR 7,5 млн за 12 мес). Для соло+агенты темп задаётся чёткостью спек и исходом спайков, а не календарём. Нужны измеримые гейты, а не амбиции.

## Решение
**North Star:** число пойманных мыслей, **дошедших до действия/destination**, в неделю (MVP-1 — часов встреч расшифровано/нед). Гейты — **go/no-go по hard-порогам**, а не годовые цифры:

| Гейт | Hard-порог (ориентир) |
|---|---|
| Wave 0 → MVP-0 | S1–S5 зелёные на ≥2 OEM (вкл. Xiaomi/Samsung) |
| MVP-0 → MVP-1 | activation >40%, W4-retention >25% |
| MVP-1 → V1 | Free→Paid 3–6%, gross margin >50% после AI-стоимости |
| Операционные (всегда) | WER на ru-шуме <15%, crash-free >99,5%, «реплика→заметка» неск. сек |

## Последствия
- `verifier` + `memory-curator` снапшотят метрики на каждом гейте (cost-audit включён).
- Гейт открывает **фаундер**, только если hard-пороги взяты (adversarial-аудит на wave-гейте).

## Альтернативы (отклонены)
- **Годовые vanity-KPI** — не управляют решениями, создают ложную уверенность.
