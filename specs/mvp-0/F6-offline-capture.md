# MVP0-F6 — Офлайн-капчер (базовый)

## User story
Как пользователь в метро/без сети, я хочу всё равно поймать мысль с черновой расшифровкой, чтобы идея не потерялась из-за отсутствия интернета.

## Scope
- On-device STT при отсутствии сети — запись + черновой транскрипт. **Движок — Vosk (ru)** (решение A2 grill-протокола 2026-07-07: без внешнего ключа, нулевые зависимости для free-тира); **whisper.cpp — fallback только при провале качества Vosk** (провал фиксируется evidence, смена — через лог решений).
- **Модель не бандлится в APK** — скачивается при первом включении офлайн-режима; ориентир размера Vosk small-ru **~45 МБ** — документированное допущение (на ратификацию в PR фазы).
- Синхронизация и ре-транскрипция (через облачный STT) при появлении сети; **очередь ре-транскрипции живёт в inbox-сторе F1 (ADR-015)** — отдельная персистенция не создаётся.
- On-device STT также удешевляет free-тир (нулевая маржинальная стоимость) и продолжает работать после исчерпания облачной квоты (ADR-005).

## Non-scope
- Полная офлайн-LLM-структуризация (требует 4+ ГБ — Non-Goal). Офлайн только захват + черновой STT.

## Acceptance criteria (EARS)
- **MVP0-F6-AC1** — WHILE сеть недоступна, THE SYSTEM SHALL захватывать и черново транскрибировать офлайн (on-device), синхронизируя при появлении сети.
- **MVP0-F6-AC2** — WHEN сеть появляется, THE SYSTEM SHALL ре-транскрибировать офлайн-захваты облачным STT (качество) и обновить заметку.
- **MVP0-F6-AC3** — IF on-device модель недоступна/не загружена, THEN THE SYSTEM SHALL хотя бы сохранить аудио и пометить для последующей транскрипции.
- **MVP0-F6-AC4** — THE SYSTEM SHALL держать офлайн-захват без потери (аудио + черновой текст), даже при последующем перезапуске приложения.

## Edge-cases / unhappy-path
- Большой офлайн-аудио → лимит длины + предупреждение.
- Расход батареи on-device STT → не гонять постоянно, только в офлайн-сессии.
- Расхождение черновой↔финал транскрипт → показать обновление, не дублировать заметку.

## Test plan
- Unit: офлайн-детект, очередь ре-транскрипции, персистентность.
- Integration: офлайн→онлайн ре-транскрипция (мок облачного STT).
- Instrumented: airplane-mode сценарий на устройстве; перезапуск с непустой очередью.

## Data / privacy
Офлайн-аудио — локально шифровано; при sync → RF-облако (ADR-004).

## Model hints
- Интеграция Vosk/whisper.cpp + очередь — T3 (нативное, батарея).
