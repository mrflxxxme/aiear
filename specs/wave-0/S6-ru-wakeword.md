# S6 — Русский on-device wake-word «Эй, бадди» (оценочный, не блокирующий)

## Гипотеза
На **взведённом** сервисе (пока наушники подключены, CDM → mic-FGS) on-device hotword-движок детектирует wake-word **«Эй, бадди»** (Buddy — ратифицировано фаундером, grill 2026-07-07 §1.1) и стартует захват без касания экрана — в пределах разумного бюджета батареи. **Движок — сначала Vosk-keyword** (решение A3: не вводить новый секрет без нужды); **Porcupine (Picovoice) — только после добавления Picovoice-ключа в env**. Риск: качество ru-hotword, расход батареи. **Не блокирует MVP-0**; исход определяет скоуп MVP-0.x.

## Acceptance criteria (EARS)
- **S6-AC1** — WHILE наушники подключены и сервис захвата взведён, THE SYSTEM SHALL детектировать wake-word «Эй, бадди» и стартовать сессию захвата без касания экрана, с **false-reject ≤ 10%** и **false-accept ≤ 1/час фонового аудио** (числовые пороги — документированное допущение, на ратификацию в PR фазы).
- **S6-AC2** — WHILE wake-word-слушание активно, THE SYSTEM SHALL удерживать доп. расход батареи **≤ 3%/час** (бюджет; VAD-гейт перед инференсом).
- **S6-AC3** — IF наушники отключены, THEN THE SYSTEM SHALL останавливать wake-word-слушание (не слушать 24/7).

## Метод
1. Keyword-детекция «эй бадди» в **Vosk-keyword** (ru, без внешнего ключа — A3); Porcupine с кастомным словом — только после появления Picovoice-ключа в env/CI-secrets.
2. VAD-гейт перед инференсом hotword (экономия батареи).
3. Интеграция на взведённый сервис (после S1/S2).
4. Замер: false-accept/false-reject rate, расход батареи за час слушания.

## Device-матрица
| Устройство | Фокус | Результат |
|---|---|---|
| Pixel 8 | точность + батарея | — |
| Xiaomi | батарея под MIUI | — |

## Go / No-Go (оценочный)
- **wake-word едет в MVP-0.x**, если: AC1 в пороги (false-reject ≤10%, false-accept ≤1/час) + AC2 батарея ≤3%/ч на ≥2 устройствах.
- **Откладывается**, если батарея/точность не тянут — тогда активация MVP-0 = tile/CDM/media (S2/S3), без wake-word.

## Что решает исход
Скоуп MVP-0.x (ADR-009). Anytime-wake-word (убитое приложение / без наушников) — вне скоупа, только V1 (default-ассистент).

## Эскалация
Если ru-hotword фундаментально слаб — зафиксировать как constraint, перенести в V1 (роль ассистента + DSP-hotword).
