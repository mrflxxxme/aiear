# golden/ — golden dataset'ы AI-контура (F2, F7)

> Канонические наборы для evaluator'а (live-gold, ADR-010). Пороги гейтов ратифицированы
> фаундером (grill 2026-07-07 §3.3, §3.4). Файлы — JSONL (одна запись = одна строка).

## Файлы

### `f2-structuring.jsonl` — классификация/структурирование мысли (F2)

Поля записи:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный id кейса (напр. `f2-0042`) |
| `input_transcript` | string | Сырой ru-транскрипт (как отдаёт STT, с реальными огрехами) |
| `expected.type` | enum | Ожидаемый `type` по `thought.schema.json` |
| `expected.tags` | string[] | Ожидаемые теги (сравнение — по пересечению, не строгое равенство) |
| `expected.destination` | enum | Ожидаемый `suggested_destination` |
| `expected.cta` | object\|null | Ожидаемый `suggested_cta` (action + when; when сверяется с точностью до минуты относительно client_time кейса) |
| `difficulty` | enum | `easy` \| `medium` \| `hard` |
| `origin` | enum | `founder` (реальная реплика фаундера) \| `synthetic` (аугментация агента) \| `adversarial` (шум/мат/смешанный язык/команда-внутри-текста) |

### `f7-commands.jsonl` — голосовые команды в сессии (F7)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный id кейса (напр. `f7-0007`) |
| `utterance` | string | Реплика-команда (или мысль-НЕ-команда — негативный кейс) |
| `expected_intent` | enum | `mark_important` \| `set_destination` \| `set_cta` \| `new_thought` \| `confirm` \| `cancel` \| `none` (не команда) |
| `expected_slots` | object | Ожидаемые слоты (destination, time и т.п.) |
| `confidence_note` | string | Ожидание по уверенности (напр. «ниже 0.7 → обязателен переспрос — необратимое действие») |

## Процесс наполнения (grill §3.4)

1. **Фаундер даёт 50–100 реальных реплик** (текстом достаточно) — задача в
   `ONBOARDING-SECRETS.md` / founder-чеклисте.
2. **Агент (evaluator) размечает** их по схемам выше и **аугментирует до 300+**:
   перефразы, STT-шум (характерные ошибки распознавания), adversarial-кейсы
   (мат, смешанный язык, обрывки, команда внутри диктовки).
3. **Фаундер выборочно ратифицирует** разметку (случайная выборка ~10–15%);
   спорные кейсы правятся до прогона гейта.
4. Записи `origin: founder` — неприкосновенны (правка только фаундером);
   `synthetic`/`adversarial` агент может пополнять, лог — в PR фазы.

## Пороги гейтов (ратифицированы, grill §3.3)

| Метрика | Порог | Где применяется |
|---|---|---|
| Точность классификации `type` на golden | **≥ 85%** | F2-AC4, live-gold против реальной LLM |
| WER STT (ru, на стыке с F2) | **< 15%** | F2 live-gold (учитывается отдельно от классификации) |
| F7 confidence-порог переспроса | **0.7** — ниже для необратимых действий обязателен переспрос | F7-AC2 |

Пересмотр порогов — только ADR'ом по данным, не молча.
